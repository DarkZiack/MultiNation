# MultiNation

**MultiNation** is a **PyGame simulation game** where you design, build, and grow your own nation.

Built with Python and PyGame, this project lets you customize your own simulation while managing your nation's development, decisions, and challenges.

---

## Features

 ✔ Buildings and Indexes <br/>
 ✔ Investments and Territory Expansion <br/>
 ✖ Tech and Upgrades <br/>
 ✖ AI <br/>
 ✖ Wars <br/>

---

## How to Run and Play

1. Clone the repository  
```bash
git clone https://github.com/DarkZiack/MultiNation.git
```
2. Install dependencies
```bash
pip install pygame
```
3. Run the file "main.py"
```bash
python main.py 
```
